# Enterprise plan

## Single sign-on

The Enterprise plan includes single sign-on (SSO) with SAML 2.0 and OpenID Connect. Supported identity providers include Microsoft Entra ID, Okta, and Google Workspace. SSO is configured by an organization owner in the admin console.

## Uptime SLA

Enterprise customers receive a 99.9 percent monthly uptime SLA. If availability falls below the SLA, service credits are applied to the next invoice.

## Dedicated support

Enterprise support includes a named customer success manager and a four hour response time for critical incidents, around the clock.
